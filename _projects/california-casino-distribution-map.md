## Project Overview

I created this statewide map to organize casino locations across California and make their geographic distribution easier to understand.

The map contains 66 numbered casino locations. Each numbered point corresponds to a casino listed in the regional panels, allowing the main statewide map to remain readable while still providing detailed identification for each location.

Rather than presenting every casino as one undifferentiated set of points, I grouped the locations into regional geographic patterns. This makes it easier to see where casino locations cluster, where they are more dispersed, and how those patterns vary across California.

## Regional Organization

The map separates the casino locations into several regional groups, including:

- San Diego
- Riverside / Palm Springs
- Eastern Desert / Border
- Central Coast / Tejon
- Central Valley / Sierra South
- Sacramento / Sierra Foothills
- Wine Country / Clear Lake
- North Coast
- Far North / Northeast Interior

Each regional group uses a different point color on the statewide map.

The numbered labels connect the statewide distribution map to the detailed casino lists shown in the regional panels.

## Cartographic Approach

One of the main challenges was displaying a large number of locations without making the map difficult to read.

I used numbered points rather than placing the full casino name beside every location. This reduced visual crowding while still allowing each location to be identified through the accompanying regional lists.

I also divided California into smaller reference maps for Southern California, Central California, Sacramento / Sierra / Wine Country, and the North Coast / Far North.

These inset maps provide additional geographic context for areas where locations are concentrated more closely together.

## How to Read the Map

Each numbered dot represents a casino location.

The number matches the casino list shown in the regional panels on the left side of the map.

Point colors represent the regional map group, allowing the viewer to quickly distinguish different geographic clusters while still reading the state as a whole.

## Spatial Pattern

The map shows that casino locations are not distributed evenly across California.

Several areas form visibly dense clusters, particularly in Southern California and parts of the Sacramento and Sierra regions, while other parts of the state contain fewer and more widely separated locations.

The regional grouping makes these differences easier to compare without treating administrative or geographic boundaries as the only way to organize the data.

## Design Considerations

The project required balancing geographic detail with readability.

With 66 locations, full text labels on the statewide map would have created significant visual clutter. Numbering the locations allowed the geographic pattern to remain visible while still giving viewers access to the name and associated Tribal group for each casino.

The regional inset maps, numbered lists, colors, and statewide map were designed to work together as one information system rather than as separate graphics.
